# მოსწავლეების აღრიცხვა + SMS შეხსენება

გაშვება (დამატებითი პაკეტები არ სჭირდება, Node 18+):

    ADMIN_PASSWORD=შენი_პაროლი node server.js

გახსენი http://localhost:3000 (ლოგინი ნებისმიერი, პაროლი — ADMIN_PASSWORD).

## SMS პროვაიდერი (`SMS_PROVIDER`)
- `log` (ნაგულისხმევი) — არ აგზავნის, მხოლოდ კონსოლში წერს (ტესტისთვის)
- `smsoffice` — smsoffice.ge: `SMSOFFICE_KEY`, `SMSOFFICE_SENDER`
- `twilio` — `TWILIO_SID`, `TWILIO_TOKEN`, `TWILIO_FROM`

## მუშაობის წესი
- ყოველ მოსწავლეს აქვს თანხა, გადახდის დღე თვეში და (არასავალდებულო) აყვანის თარიღი.
- „✓ გადაიხადა" გადააქვს შემდეგ თვეზე (31-ე -> თვის ბოლო დღე).
- გადახდის წინა დღეს, `REMIND_HOUR`-ზე (ნაგულისხმევი 10:00, Asia/Tbilisi) ავტომატურად იგზავნება SMS, თითო გადახდაზე ერთხელ.
- ტექსტი იცვლება გვერდზე: `{name}` `{amount}` `{date}`.
- მონაცემები ინახება `data.json`-ში. სერვერი უნდა მუშაობდეს მუდმივად (VPS/Railway/Render + მუდმივი დისკი).

## iPhone ვერსია (სერვერის გარეშე) — `tracker/app/`
სტატიკური გვერდი (PWA): მონაცემები ინახება თავად ტელეფონში (localStorage), ჰოსტინგი/სერვერი არ სჭირდება.
გადახდის წინა დღეს გვერდზე ჩნდება „გაგზავნა SMS" — ხსნის Messages-ს მზა ტექსტით, ტრენერი აჭერს Send-ს.
გამოიყენეთ „ბექაპი" ღილაკი მონაცემების შესანახად (Safari-ს მონაცემები შეიძლება გასუფთავდეს).
უფასოდ გამოსაქვეყნებლად: GitHub Pages (ან Cloudflare Pages / Netlify Drop) — `tracker/app` საქაღალდე.
